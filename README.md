Documentation – Minification JS & CSS manuelle (sans outil)

Vous pouvez soit prendre le fichier zip soit reprendre le projet restaurant pour le minifier

Objectif

Apprendre à minifier soi-même un fichier JavaScript ou CSS en supprimant tout ce qui n’est pas indispensable à son exécution.

1. Principe de la minification manuelle

La minification consiste à :

retirer tous les espaces inutiles ;

supprimer les retours à la ligne ;

enlever tous les commentaires ;

raccourcir éventuellement les noms de variables (optionnel) ;

regrouper le code pour qu’il tienne dans le moins d’octets possible.

Le but n'est pas de rendre le code lisible, mais compact.
2. Règles de base pour minifier manuellement
  1. Supprimer les retours à la ligne
  2. Supprimer les espaces inutiles
  3. Supprimer les commentaires
  4. Retirer les guillemets inutiles en CSS
  5. Raccourcir les noms des variables si possible
